# World Music Finder

World Music Finder is an interactive map for discovering music connected to countries, linking to users' Spotify accounts to let them save songs and add them to their playlists.

## Built with

- Next.js and React
- MapLibre GL JS for the interactive map
- MapLibre's public world map style and vector tile service, used while developing the map
- Natural Earth 1:110m country boundaries as a bundled fallback beneath live vector tiles

## Development

Start the development server:

```bash
npm run dev
```

## Checks

```bash
npm run lint
```
